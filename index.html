Why NebulaDB

Designed for how you actually build

We obsessed over the details so you don't have to think about your database.

⚡

TypeScript-first, not TypeScript-afterthought

Every API is fully typed with inference. Your collections, queries, and plugins all carry their types through. Write db.collection('users').find({ role: 'admin' }) and your editor already knows the shape of every result.

🔄

Reactive by default

Subscribe to any query. When data changes, your UI knows instantly. No polling, no websockets to wire up.

🌍

Truly portable

Same code in the browser, Node, Deno, and edge runtimes. Swap adapters without touching your queries.

🔌

Plugins, not forks

Auth, encryption, sync, geospatial, audit logging — drop in what you need. Build your own in minutes.

🔍

Queries that think

Full-text search, geo queries, compound indexes, and a query optimizer that learns your access patterns.

🔒

Secure from line one

Encryption at rest, field-level encryption, and audit trails — not bolted on, built in.

Developer Experience

Feels like it was made for you

Because it was. Every API decision starts with: "would a developer love this?"

The database that disappears

You shouldn't think about your database. NebulaDB handles the hard parts — indexing, reactivity, persistence — so you can focus on your app.

  • Schema-optional: start schemaless, add structure when you're ready
  • Zero-config: working database in under 10 lines of code
  • Offline-first: your app works without a connection, syncs when it can
  • Framework bindings for React and Vue with hooks built in
app.ts
import { createDb } from '@nebula-db/core';
import { SQLiteAdapter } from '@nebula-db/adapter-sqlite';
import { createSyncPlugin } from '@nebula-db/plugin-sync';

// Persistent + synced in 12 lines
const db = createDb({
adapter: new SQLiteAdapter('./app.db'),
plugins: [createSyncPlugin({ serverUrl })]
});

const todos = db.collection('todos');
await todos.insert({ text: 'Ship it 🚀', done: false });

// Live UI updates — no refresh needed
todos.subscribe({}, docs => render(docs));
